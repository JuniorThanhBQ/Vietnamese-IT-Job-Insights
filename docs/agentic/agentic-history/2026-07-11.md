## 2. Applied Solution
* Created specialized list parsers (`ITViecListParser` and `TopDevListParser`) using Selectolax to extract job details links and detect next pages without network/DB operations.
* Configured Celery application in `crawler/celery_app.py` setting strict resource conservation limits: `worker_max_memory_per_child=250000` (250MB), `worker_max_tasks_per_child=10`, and `worker_prefetch_multiplier=1` to prevent Chromium memory leaks.
* Scheduled a nightly Celery Beat task `crawl_all_task` to run daily at 2:00 AM with a page depth limit of 5 pages.
* Created tasks in `crawler/tasks.py` leveraging `asyncio.run` to orchestrate HTML fetching, list parsing, and job URL queueing with automatic Celery retries and exponential backoff (`retry_backoff=True`).
* Implemented `GeminiEmbeddingService` in `backend/app/modules/jobs/embedding_service.py` with automatic round-robin API key rotation on 429 too many requests errors.
* Added `upsert_embedding` and `search_similar_jobs` to `JobRepository` utilizing pgvector's `cosine_distance` operator.
* Integrated embedding generation inside `JobService.post_job` to automatically generate and store embeddings when jobs are created or updated.
* Created `JobSemanticSearchResponse` model and implemented the `GET /api/v1/jobs/search` route in `backend/app/modules/jobs/routers.py` to expose semantic search.
* Added `langchain-core` to the dependencies in `backend/pyproject.toml` and installed it in the virtual environment.
* Created `GeminiChatService` in `backend/app/modules/jobs/rag_service.py` utilizing LangChain Core messages (`SystemMessage`, `HumanMessage`, `AIMessage`) and raw HTTP stream integration (`alt=sse`) to implement key rotation in streaming.
* Implemented view method `stream_chat` in `JobViews` converting raw LLM chunks to valid SSE format (`data: ...\n\n`).
* Created `POST /jobs/chat` route in `backend/app/modules/jobs/routers.py` utilizing FastAPI `StreamingResponse`.
* Created pytest unit tests in `backend/tests/test_rag_service.py` verifying RAG streaming and key rotation.
* Verified that Pylint score for the backend and crawler are at a perfect `10.00/10` and pytest executions pass successfully.
